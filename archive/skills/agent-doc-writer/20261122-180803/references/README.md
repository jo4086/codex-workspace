# Reference Index

## Purpose

Route Markdown authoring work to the guidance for document responsibility, agent instructions, README roles, and navigation.

## References

| Reference | Responsibility | When to Read |
| --- | --- | --- |
| [writing.md](./writing.md) | Preservation, document ownership, progress checklists, length, and splitting | Creating, revising, or splitting Markdown |
| [agents.md](./agents.md) | `AGENTS.md` and `README.md` roles and instruction boundaries | Writing either file or changing their relationship |
| [readmes.md](./readmes.md) | Project, area, docs, and category README content | Writing or revising a README |
| [navigation.md](./navigation.md) | README placement, relative links, and index maintenance | Adding, moving, deleting, or connecting documents |

## Usage

Start with the reference for the requested document change. Combine references only when the task spans their responsibilities; for example, an `AGENTS.md` and README update may also need navigation checks.
