# Create from User Request

## Purpose

Create a Skill from explicit user requirements when no planned specification is the source of truth.

## Workflow

1. Extract the requested capability, activation conditions, constraints, target location, and completion criteria.
2. Inspect applicable instructions and related Skills before choosing a structure.
3. Identify responsibility overlap and assign ownership rather than copying another Skill's guidance.
4. Ask only about missing decisions that materially change the result and cannot be inferred from repository conventions.
5. Choose the smallest structure that supports the actual workflows. A focused Skill may need only `SKILL.md`; substantial conditional guidance may need references and indexes.
6. Write supporting resources before the entrypoint.
7. Validate metadata, routing, links, formatting, behavior, and compliance with the request.

## Boundaries

Do not add scripts, assets, UI metadata, templates, examples, or categories without a concrete workflow need. Do not install or activate the Skill unless separately authorized.
