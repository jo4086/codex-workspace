# SKILL.md Template

Use only sections needed by the Skill. Replace bracketed fields and remove unused sections.

```markdown
---
name: skill-name
description: Brief capability and when this Skill applies.
---

# Skill Title

## Purpose

State the outcome and activation boundary.

## Core Principles

- Include only shared, decision-changing guidance.

## Reference Routing

- For a specific concern, read [references/topic.md](./references/topic.md).

## Workflow

1. Inspect relevant context and requirements.
2. Load only applicable references.
3. Implement within scope.
4. Run relevant validation.

## Cross-Skill Coordination

- State ownership and when another available Skill applies.

## Restrictions

- Preserve explicit scope and authorization boundaries.
```

Do not retain empty sections or placeholder wording in a completed Skill.
