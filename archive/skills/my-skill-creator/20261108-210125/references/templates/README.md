# Templates Reference Index

## Purpose

Provide adaptable Markdown starting points for required Skill documents without imposing unused sections.

## References

| Reference | Responsibility | When to Read |
| --- | --- | --- |
| [skill.md](./skill.md) | Minimal `SKILL.md` shape | Drafting a new Skill entrypoint |
| [reference.md](./reference.md) | Focused reference document shape | Drafting an individual reference |
| [index.md](./index.md) | Root and category index shapes | Drafting a reference index |

## Usage

Copy only the relevant shape, replace example content, and remove unused sections. Explicit requirements and existing conventions override template defaults.
