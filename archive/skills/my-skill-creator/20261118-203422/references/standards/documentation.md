# Skill Documentation Standards

## Requirements

- Use English Markdown unless the user requests another language.
- Keep each Skill document independently actionable: include the instructions required to perform its responsibility rather than relying on another Skill to supply them.
- Use LF line endings.

## Entrypoint Content

Keep shared purpose, activation conditions, essential constraints, workflow selection, reference routing, and necessary Cross-Skill coordination in `SKILL.md`. Move conditional procedures, schemas, extensive examples, and mode-specific rules to references.

## General Markdown Guidance

Apply `agent-doc-writer` for general Markdown structure, revision, preservation, document focus, length review, splitting, and navigation. This standard adds only Skill-specific content boundaries and required document behavior.
