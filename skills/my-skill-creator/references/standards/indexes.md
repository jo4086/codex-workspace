# Reference Index Standards

## Root Index

Use this order:

1. `# Reference Index`
2. `## Purpose`
3. `## Reference Categories` or `## References`
4. `## Usage`

Use a Markdown table with names, descriptions, and relative links. Route every maintained category or direct reference from this index.

## Category Index

Use this order:

1. `# <Category> Reference Index`
2. `## Purpose`
3. `## References`
4. `## Usage`

Use these columns:

| Reference | Responsibility | When to Read |
| --- | --- | --- |
| Relative document link | Guidance owned by the document | Condition for loading it |

## Accuracy

Each index must reflect actual files. Add, rename, move, or remove an entry with its target document. State when each target should be read so agents can avoid unrelated context. Verify every relative target from the file containing the link.
