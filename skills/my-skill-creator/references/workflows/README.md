# Workflows Reference Index

## Purpose

Route Skill creation, extension, and review work to the procedure matching its source and scope.

## References

| Reference | Responsibility | When to Read |
| --- | --- | --- |
| [from-tbd.md](./from-tbd.md) | Convert a repository TBD specification into a Skill | Implementing a Skill from `TBD/skills/<skill-name>/README.md` |
| [from-request.md](./from-request.md) | Create a Skill from direct user requirements | No TBD specification is the source of truth |
| [extending.md](./extending.md) | Extend or review an existing Skill safely | Changing or assessing an implemented Skill |

## Usage

Choose the workflow matching the request. Read multiple documents only when work genuinely combines creation, extension, or review modes.
