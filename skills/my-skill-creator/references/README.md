# Reference Index

## Purpose

Route Codex Skill creation and maintenance work to focused workflows, standards, and document templates for this repository.

## Reference Categories

| Category | Description | Index |
| --- | --- | --- |
| Workflows | Procedures for creation from TBD, creation from requests, extension, and review | [README](./workflows/README.md) |
| Standards | Structure, documentation, index, Cross-Skill, and validation requirements | [README](./standards/README.md) |
| Templates | Adaptable shapes for entrypoints, references, and indexes | [README](./templates/README.md) |

## Usage

Start with the workflow matching the request. Load only standards needed for current decisions, then use a template when drafting that document type. Explicit user requirements and existing Skill conventions override template defaults.
