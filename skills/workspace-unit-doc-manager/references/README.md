# Reference Index

## Purpose

Route workspace-unit documentation work to lifecycle rules or focused operating workflows without loading unrelated context.

## Usage

Read [REQ Document Lifecycle](./document-lifecycle.md) when creating, locating, linking, or evaluating lifecycle documents. Read [Session Workflows](./session-workflows.md) for task execution, next or remaining work briefings, focused discovery, Phase progression, or a target `AGENTS.md` conflict. Read [User-Written Requests](./user-request-intake.md) when the user points to a submission under `docs/user/`.
