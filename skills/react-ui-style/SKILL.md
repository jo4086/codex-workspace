# React UI Style

Apply this Skill when a React UI task needs a project visual convention beyond the task and existing code.

## Working Principles

- Inspect the affected UI and reuse its established components, tokens, styling system, and behavior.
- Preserve requested visual preferences, responsive behavior, and existing functionality.
- Keep the implementation proportionate to the task. Let ordinary HTML, React, layout, and interaction decisions follow the task and project code.
- Do not add dependencies or replace an established design system without a requirement.

## References

Read [references](./references/README.md) only when the task matches a listed convention. Skip references that do not apply.

## Boundaries

This Skill owns presentation and task-specific UI behavior. `react-router` owns route structure and navigation architecture. `code-style` owns code organization and conventions.
