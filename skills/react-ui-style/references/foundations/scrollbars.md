# Scrollbars

Apply this reference only when the task specifies scrollbar appearance.

- Preserve the project's existing scrollbar behavior unless the task changes it.
- A thin visible scrollbar is the default when no style is established.
- Use transparent idle, activity-reveal, or always-transparent styles only when the requirement selects that behavior for the affected region.
- Keep the region scrollable and avoid changing its geometry as appearance changes. Verify target-browser support when an exact visual state matters.
