# Foundations

Core visual design guidelines for React user interfaces.

## Reference Index

| Document                         | Responsibility                                                      | Read When                               |
| -------------------------------- | ------------------------------------------------------------------- | --------------------------------------- |
| [layout.md](./layout.md)           | Viewport, width strategies, responsive layouts, alignment, overflow | Creating or modifying visual layouts    |
| [typography.md](./typography.md)   | Text hierarchy, fonts, readability, wrapping, numeric text          | Creating or modifying text presentation |
| [iconography.md](./iconography.md) | Icon selection, sizing, alignment, semantics, accessibility         | Adding or modifying icons               |
| [scrollbars.md](./scrollbars.md) | Scrollbar thickness, visibility states, and interaction checks | Styling a scroll region's scrollbar |

## Reference Rules

1. Read only the documents relevant to the current task.
2. Combine references when the task spans multiple visual concerns.
3. Prioritize existing project design conventions over default guidelines.
4. Avoid introducing new design systems or dependencies unnecessarily.
5. Do not load unrelated references.

## Deferred References

The following documents may be introduced when dedicated guidelines become necessary:

- `colors.md` — Color palettes, semantic colors, theme tokens, and contrast.
- `spacing.md` — Spacing scales, density, rhythm, and consistent gaps.

Until then, follow the project's existing design tokens, Tailwind configuration, and component conventions.
