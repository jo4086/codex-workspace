# Layout

Use the affected page's existing layout and responsive conventions.

- On dense dashboards and edit pages, use space for the work. Add card wrappers only when they clarify grouping. Spacing or dividers can separate regions with less visual weight.
- Size fields for their content and task. Use full width when the interaction benefits from it or a narrow viewport requires it.
- In composite controls, align dividers, child heights, padding, and content so the component remains visually stable.
- Preserve usable scrolling and avoid layout shifts caused by the requested change.

Route structure and route-layout composition belong to `react-router`.
