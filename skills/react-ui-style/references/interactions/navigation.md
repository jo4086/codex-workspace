# Navigation and Disclosure

Preserve the project's router, links, navigation state, and disclosure behavior.

- Keep route structure, URL behavior, and client-side navigation with the routing solution.
- Keep a user's context, such as scroll, selection, or filters, when the product already preserves it.
- Do not hide essential destinations behind hover-only UI.
- For a custom transient menu, preserve the established dismissal and focus behavior.

Choose the implementation of ordinary navigation and disclosure from the task and project. `react-router` owns routing architecture.
