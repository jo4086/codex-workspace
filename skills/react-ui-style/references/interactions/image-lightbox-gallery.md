# Image Lightbox Gallery

Use this pattern when readers need to inspect content images or browse images from one item. Do not add it automatically to logos, icons, decorative images, or every standalone image.

- Preserve each image's aspect ratio and fit it in the available viewing area before zooming.
- Keep any existing image-click behavior separate from the action that opens the gallery.
- Show images from the same item in content order. Provide an obvious current-image indicator and a way to choose another image when several images exist.
- Keep the gallery dismissible without treating image manipulation or image selection as dismissal.
- Preserve the underlying page's scroll position when the gallery closes.
- Reuse existing dialog, image, and gallery components when they meet the requested behavior.
